## Опис програми
Програма автоматично заповнює матрицю випадковими числами, знаходить серед них мінімальне значення та виводить його на панель управління. Після цього алгоритм множить кожен елемент масиву на знайдений мінімум і виконує комбіноване сортування стовпців залежно від їхньої парності. Весь процес реалізовано на базі C++ Windows Forms, що забезпечує наочне відображення обробки даних у таблиці в реальному часі.

## Як виконується програма
Виконання програми починається з натискання кнопки генерації, яка створює матрицю та заповнює її випадковими цілими числами. На наступному етапі алгоритм послідовно знаходить мінімальний елемент усій таблиці та проводить математичне перерахування значень у кожній клітинці. Завершується процес автоматичним сортуванням, де непарні стовпці вишиковуються за спаданням, а парні - за зростанням для впорядкування даних.
